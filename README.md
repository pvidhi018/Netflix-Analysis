# Netflix Movies and TV Shows Analysis Using Power BI

## Project Overview

Netflix has a huge collection of movies and TV shows, with a lot of data to explore. For this project, I created an interactive Power BI dashboard to learn how to build interactive reports and make it easier for users to explore Netflix data.

The dataset was already cleaned because the main goal of this project was to practice creating an interactive dashboard in Power BI. I focused on adding buttons, cards, charts, filters, and a map so users could explore the data in different ways.

## Project Objectives
- Create an interactive Power BI dashboard for Netflix movies and TV shows.
- Use buttons to switch between movies and TV shows.
- Display important information such as the number of titles, average ratings, and votes.
- Explore titles by rating group and genre.
- Show country-wise details using a table and an interactive map.
- Make it easy for users to compare different types of Netflix content.

## Tools Used

- **Power BI:** Used to create the interactive dashboard, cards, charts, filters, and map visualizations.
- **Cleaned Netflix Dataset:** Used as the data source for the dashboard.

## Dashboard Key Features 

1. Interactive Movie and TV Show Buttons
I started by creating two simple buttons: **Movies** and **TV Shows**.

When a user clicks one of these buttons, the dashboard filters the data based on the selected content type. This makes it easy to explore movie-related information separately from TV show or series data.

2. Three Main KPI Card Sections
I created three main card sections to display key information:

- **Overall Summary:** Shows the total number of movies and TV shows, average rating, and votes.
- **Movies Summary:** Shows the number of movies, their average rating, and related vote information.
- **TV Shows Summary:** Shows the number of TV shows or series, their average rating, and related vote information.

For example, when the user clicks the Movies button, the movie card displays the movie-related figures. This helps users focus on the information they want to explore.

3. Funnel Chart — Titles by Rating Group
I used a funnel chart to show the number of titles in each rating group.

This helps users see how Netflix titles are distributed across different ratings and compare the number of titles between rating groups.

4. Title Filter with Show Images, Ratings, and Votes
On the other side of the dashboard, I added a filter to explore individual titles. The selected title is displayed with its image, rating, and number of votes.

This feature makes it easier to look up a particular movie or TV show and view its related information in one place.

5. Bar Chart — Average Ratings by Genre
I added a bar chart to compare average ratings across different genres, along with the number of titles in each genre.

This allows users to explore how genres compare in terms of average ratings and how many titles are available in each genre.

6. Country-Wise Data Table
I created a table showing country-wise details, including:
- Number of titles
- Average rating
- Total number of votes
- Average number of votes per title

This table helps users compare Netflix content across countries and see how the figures differ from one country to another.

7. Interactive Map with Bubble Visualization
I also added a geographical map with bubbles to display Netflix data by country.

The map allows users to explore the following measures:
- Number of titles
- Average rating
- Total number of votes
- Average number of votes per title

The size of each bubble represents the total number of titles in that country by default.

I also added buttons that allow users to switch the measure displayed on the map. When a user selects the number of titles, average rating, number of votes, or average votes per title, the map updates to show that measure country by country. The bubble sizes change according to the selected measure, making it easier to explore and compare the data visually.


## Project Summary

The main focus of this project was to improve my Power BI dashboard-building skills and understand how to make reports more interactive and user-friendly. By combining cards, charts, filters, and an interactive map, I created a dashboard that allows users to explore Netflix movies and TV shows from different perspectives.
